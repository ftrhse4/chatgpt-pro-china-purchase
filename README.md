## 国内直接付款，卡在哪一步

官方订阅走 Stripe，对支付环境的要求比较苛刻。常见的拒付原因有三类：

1. 卡本身不支持国际支付网络，银联信用卡基本无望
2. 账单地址和所用 IP 的地区对不上，触发 Stripe 风控拦截
3. 网络环境不稳定，注册、登录、付款过程中频繁切换地区，被判定为异常

就算三样都对上了，国内发行的双币卡被拒也不少见。这是风控概率问题，多试几次或者换一条支付路径都正常，不必反复在同一张卡上死磕。

## 在国内怎么买：三条可行路径

### 路径一：国际信用卡官网直订

最稳的方式，也是官方最推荐的一种。在设置里进入升级套餐页面，选好档位，填卡号、有效期、CVV 和账单地址，付款成功账号立即升级。关键点是账单地址尽量与你的网络环境保持一致，否则大概率被 Stripe 拦下。前提是手里得有一张能国际支付的 Visa 或 Mastercard，没有的话这条路直接排除。

### 路径二：App Store 内购或苹果礼品卡

iPhone、iPad 用户可以在 ChatGPT App 里订阅，用 Apple ID 付款，全程不碰国际卡。两个坑提前知道：

- iOS 客户端不能从免费版直接升 Pro。免费用户在 App 里只能看到 Go 和 Plus 两个选项，想一步到位订 Pro，必须走网页端操作

礼品卡路线是先买美区 Apple Gift Card 充进 Apple ID，再在 App 内订阅。适合不想暴露卡信息的人，但流程多一步，汇率折算后未必更便宜。

## 常见问题

**充值失败怎么办？**
先检查卡是否支持国际支付、余额是否充足、有没有开交易限制；账单地址的国家地区要和填写信息一致；网络环境避免频繁切换节点。走第三方平台的话，选明确承诺失败退款的，下单前把退款规则读一遍。

**升级后还要手机号验证吗？**
部分免费账号使用 Codex 时会触发手机号验证。代充平台收集的客服反馈显示，先升级 Plus 或 Pro 再重新登录，绝大多数账号不再出现原来的验证提示；升级后仍需验证的，以账号页面实际提示为准。

**订阅后能退款吗？**
官方订阅的退款按 OpenAI 政策处理，购买前先想清楚是否长期使用、要不要自动续费。第三方平台看各自规则，确认退款条款再付款。

**$100 和 $200 到底怎么选？**
